对象 ​

对象具有多个不同类型，如何实现对象名：类型的ts格式？

通过接口interface来实现

  1. 先定义一个接口interface，指明有哪些类型及变量名称
  2. 将对象名的类型设置为该接口名，即实现了ts的需求
ts
//先定义接口
interface Person{
    name:string
    age:number
    isMarried:boolean
    //方法在接口内声明格式：
    //方法名：(形参)=>返回值类型
    dance:()=>void
}
//再用该接口作为对象的类型名称
let jcher:Person={
    name:'jcher',
    age:19,
    isMarried:false，
   	dance:()=>{
        console.log('我来跳个青海摇')
}
}

注意：interface接口不需要用逗号隔开每一行，但是实际初始化的时候是需要用逗号隔开每一行的。

联合 ​

第一种用处

当一种变量存在不同的类型需求时，应该怎么办呢？

用联合解决这个问题，即用类型1|类型2|类型3，字面上看就是用或门来解决

举例

ts
let judge:string|number=90
//可以将成绩赋值为等级A、B、C
judge=A

第二种用处

可以将变量值限制在一定的范围内

例子

ts
let name:'jcher'|'tjc'|'jc'=变量
此时，变量只能填三个值，就是'jcher''tjc''jc'

枚举 ​

作用跟联合的第二个用处是一样的，限制取值范围

用法步骤：

  1. 定义枚举类型（常量列表）
  2. 使用枚举类型约束取值范围

举例

ts

const ThemeColor{
    red:'#ff0f29',

    Green:'#30b30e'

添加 ​

  • 在开头添加：unshift()
  • 在末尾添加：push()
ts
let songs:string[]=['海阔天空','友情岁月','晴天']
let newLength=songs.unshift('搁浅','千千厥歌')
console.log('第一次添加后长度为',newLength)
newLength=songs.push('如愿','红马鞍')
console.log('第二次添加后长度为',newLength)
console.log('songs数组元素为：',songs)

打印结果：
第一次添加后长度为 5
第二次添加后长度为 7
songs数组元素为： 搁浅,千千厥歌,海阔天空,友情岁月,晴天,如愿,红马鞍

  • 在开头删：unshift----shift

let songs:string[]=['海阔天空','友情岁月','晴天']

阶段综合 - 生肖抽卡 ​

ts
interface ImageCount{
  url:string
  count:number
}
interface phone{
  url:string
}
@Entry
@Component
struct Index {
  @State images:ImageCount[]=[
    {url:'app.media.bg_00',count:0},
    {url:'app.media.bg_01',count:0},
   {url:'app.media.bg_02',count:0},
    {url:'app.media.bg_03',count:0},
   {url:'app.media.bg_04',count:0},
    {url:'app.media.bg_05',count:0}
  ]
  @State phones:phone[]=[
    {url:'app.media.xm'},
    {url:'app.media.hw'},
    {url:'app.media.pg'}
  ]
  //用于控制显隐的参数
  @State maskOpacity:number=0
  @State maskZIndex:number=-1
  //用于控制缩放的参数
  @State scaleX:number=0
  @State scaleY:number=0
  //生成0-5的随机数
  @State randomIndex:number=Math.floor(Math.random()*6)
  //生成0-2的随机数
  @State randomPhone:number=Math.floor(Math.random()*3)
  //是否集齐卡片
  @State isGet:boolean=false
  build() {
      //生肖抽卡案例
      Stack(){
        //抽卡界面
        Column(){
          Grid(){
            ForEach(this.images,(item:ImageCount,index:number)=>{
              GridItem(){
                Badge({
                  count:item.count,
                  position:BadgePosition.RightTop,
                  style:{
                    badgeSize:20,
                    fontSize:12,
                    badgeColor:'#666'
                  }

                }){
                  Image($r(item.url))
                    .width(80)
                }
              }

            })
          }
          .width('100%')
          .height(300)
          .columnsTemplate('1fr 1fr 1fr')
          .rowsTemplate('1fr 1fr')
          .margin({top:80})
          Button('立即抽卡').width(200).margin(30).backgroundColor('#ec4482')
            .onClick(()=>{
              this.maskOpacity=1
              this.maskZIndex=99
              this.scaleX=1
              this.scaleY=1
              //生成0-5的随机数
              this.randomIndex=Math.floor(Math.random()*6)
              //生成0-2的随机数
              this.randomPhone=Math.floor(Math.random()*3)
            })


        }
        //遮罩层
        Column(){
          Text('获得生肖卡').fontColor('#fff').fontWeight(700).fontSize(22).margin({bottom:20})
          Image($r(`app.media.img_0${this.randomIndex}`))
            .width(200)
            .margin({bottom:20})
          //缩放图片加动画
            .scale({
              x:this.scaleX,
              y:this.scaleY
            })
            .animation({
              duration:200
            })
          Text('开心收下').width(200).height(50).textAlign(TextAlign.Center).fontColor('#fff').border({width:2,color:'#fff'}).borderRadius(25)
            .onClick(()=>{
              this.maskOpacity=0
              this.maskZIndex=-1
              this.scaleX=0
              this.scaleY=0
              //要想让复杂类型中的数据动态更新，需要更新所有内容
              this.images[this.randomIndex]={
                url:`app.media.img_0${this.randomIndex}`,
                count:this.images[this.randomIndex].count+1
              }
              //判断是否集齐 默认集齐
              this.isGet=true
              for(let item of this.images){
                //只有没集齐才会进入该分支
                if(!item.count){
                  this.isGet=false
                  break
                }
              }

            })

        }
        .width('100%')
        .height('100%')
        .justifyContent(FlexAlign.Center)
        .backgroundColor('#e6323232')
        .opacity(this.maskOpacity)
        .zIndex(this.maskZIndex)
        //手机遮罩层
        if(this.isGet){
          Column(){
            Text('恭喜获得手机一部').fontColor('#fff').fontWeight(700).fontSize(22).margin({bottom:20})
            Image($r(this.phones[this.randomPhone].url))
              .width(200)
              .margin({bottom:20})
            Text('再来一次').width(200).height(50).textAlign(TextAlign.Center).fontColor('#fff').border({width:2,color:'#fff'}).borderRadius(25)
              .onClick(()=>{

                //将对象数组中的数字清零
                this.images=[
                  {url:'app.media.bg_00',count:0},
                  {url:'app.media.bg_01',count:0},
                  {url:'app.media.bg_02',count:0},
                  {url:'app.media.bg_03',count:0},
                  {url:'app.media.bg_04',count:0},
                  {url:'app.media.bg_05',count:0}
                ]
                this.isGet=false

              })

          }
          .width('100%')
          .height('100%')
          .justifyContent(FlexAlign.Center)
          .backgroundColor('#e6323232')
        }
        }

  }
}

该案例需要注意的几个点：

  • 不能直接修改对象数组中的属性来更新界面，这是由于复杂数据类型往往数据量较大，若能直接通过属性修改，则会降低性能，所以只能整个对象重新赋值或者对象下属第一层重新赋值来达到更新的目的，在上面案例中的体现：

    ts
    this.images[this.randomIndex]={
                url:`app.media.img_0${this.randomIndex}`,
                count:this.images[this.randomIndex].count+1
              }
//不能直接this.images[this.randomIndex].count++  页面不会更新 虽然数值确实变了

  • 动画效果的添加：只要存在变化，就可以通过animation来添加动画效果，比如duration:1000就是持续时间，scale用来放大缩小图片的比例，用法是scale({x:,y:})，分别设置x、y上的比例

http请求 ​

如果需要申请网络资源，http请求是必不可少的。（如果对实时性要求比价高，比如后端的数据一旦发生变化需要立马传递给客户端的话，可以利用websocket实现双向实时通信，WebSocket官方文档）

需要说明的是，在浏览器和模拟器中使用网络请求需要在module.json5文件中申请INTERNET权限

ts
//申请权限
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
    ]

一般使用步骤

  1. 创建请求对象
ts
let httpRequest = http.createHttp()
  1. 创建请求体
ts
let options: http.HttpRequestOptions = {
    //请求方式
      method: http.RequestMethod.POST,
    //请求头
      header: {
        'Content-Type': 'application/json'
      },
    //post发送所需要的额外参数
      extraData:{}
    }
  1. 发送请求，捕获错误信息
ts
httpRequest.request('url地址',options,(err:bussinessError)=>{
    //打印错误信息
    if(err){
        console.log('err:',err)
    }
})

涉及的单位问题

在arkts中，宽高的默认单位是vx（虚拟像素），而背景图片尺寸属性中设置的宽高，都是以px作为默认单位，但是根据分辨率和刷新率的不同，相同px在不同设备中展现的大小不一样，而vx则可以解决这个问题，vx会自动根据设备的分辨率转换为对应的px，从而保证了不同设备呈现的效果一致。

因此，如果想让背景图片的大小和位置根绝盒子的大小来移动改变，则要用到vp2px()函数

线性布局 ​

css中的flex单行布局 就是没有换行这个功能，如果需要换行的话，则需要使用到flex布局。

对于column容器，主轴是垂直方向，row容器的主轴是水平方向

设置主轴方向的属性通过justifycontent,属性值通过FlexAlign枚举

设置侧轴的属性通过alignitems,属性值要根据侧轴所在的方向所决定：

  • 侧轴水平：通过HorizontalAlign枚举
  • 侧轴垂直：通过VerticalAlign枚举

UIAbility组件 ​

  • 一种包含用户界面的应用组件，主要用于与用户交互。

  • 每一个UIAbility实例都对应了任务列表的一个任务。（可参考微信小程序，每个小程序都会在后台有一个任务）

关系图：

  • 一个应用可以包含多个模块，刚初始化的应用一般是entry，可以在根目录右键选择新建module
  • 每个module下面又可以创建多个UIAbility
  • 每个UIAbility下面包含了多个page，也就是用户所看到的界面

如何实现同模块UIAbility拉起？

开发者需求：如在微信中聊天时，点击微信买菜可跳转到买菜的界面。

步骤：

  1. 获取上下文环境（可理解为一个方法库，需要调用里面的方法）
    1. 调用startAbility
ts
//1.获取上下文环境(注意强制类型转换为UIAbilityContext)
  context=getContext(this) as common.UIAbilityContext
//2. 调用startAbility 
  let want:Want={
              //ability实例所在包名
              bundleName:'com.example.zzjj_02',
              //所在模块名
              moduleName:'entry',
              //ability实例名称
              abilityName:'EntryAbility1',
              //可选，用于传递参数

            }
   this.context.startAbility(want)

持久化（用户首选项） ​

用户首选项为应用提供Key-Value键值型的数据处理能力，支持应用持久化轻量级数据，并对其修改和查询。当用户希望有一个全局唯一存储的地方，可以采用用户首选项来进行存储。Preferences会将该数据缓存在内存中，当用户读取的时候，能够快速从内存中获取数据，当需要持久化时可以使用flush接口将内存中的数据写入持久化文件中。Preferences会随着存放的数据量越多而导致应用占用的内存越大，因此，Preferences不适合存放过多的数据，也不支持通过配置加密，适用的场景一般为应用保存用户的个性化设置（字体大小，是否开启夜间模式）等。

1.引入用户首选项

ts
import {preferences} from '@kit.ArkData'

2.初始化变量

ts
let FirstEnterPreference:preferences.Preferences|null=null

3.实例化preference：传入两个参数

context:相当于仓库中特定的一块地址，先要获取getcontext，然后作为参数传给getpreferenceSync方法

option:主要用来给preference命名

ts
//获取用户首选项实例方法
  getFirstEnterPreference(){
    let context=getContext(this) as Context
    FirstEnterPreference=preferences.getPreferencesSync(context,{name:'FirstEnterPreference'})
  }

4.定义获取数据方法

ts
getPreference(){
    //从仓库获取isEnter属性的value值，没拿到就默认为false
    return FirstEnterPreference?.getSync('isEnter','false') as string
  }

5.定义存放数据方法

ts
putPreference(isEnter:string){
    FirstEnterPreference?.putSync('isEnter',isEnter)
    //flush方法手动存入仓库中确保数据不丢失，若遇到error执行回调函数打印错误信息
    FirstEnterPreference?.flush((err:BusinessError)=>{
      if(err){
        console.log('错误信息:',err.message);
      }
    })
  }

6.页面加载就更新数据

ts
aboutToAppear(): void {
    //实例化
    this.getFirstEnterPreference()
    //更新值
    this.isEnter=this.getPreference()
    //已经不是第一次
    if(this.isEnter=='true'){
      //直接去首页
      router.replaceUrl({url:'pages/Index'})
    }
  }
